Docker Sandboxes

API v1

Overview

Files

GETList lists directory entries by path ascending. DELETERemove deletes a path. GETReadFile returns raw file content over HTTP; Stat exposes file metadata. PUTWriteFile accepts raw content with path and mode query parameters. PUTMkdir creates a directory. GETDownload streams file headers, bytes, and per-file errors. POSTMove renames or moves a path. GETStat reads metadata for one path. POSTUpload streams one or more files.

Processes

GETListProcesses lists processes in creation order. POSTCreateProcess starts a durable interactive process and returns its resource name. POSTExec runs one command to completion. GETGetProcess reads one process by its endpoint-scoped resource name. GETInteract binds the complete process name from the path to the first Attach frame. GETReadOutput returns one page of retained output after a stream_sequence, the same cursor Interact resumes from, so a REST client can read what a process printed. POSTSignal sends one signal to an existing process.

Credentials

POSTExchangeDockerCredential consumes an identity token once for the authenticated owner.

Images

GETListImages lists images in the caller's owner scope. POSTCreateImage registers pushed OCI content or disk content derived from a snapshot or sandbox. GETGetImage reads one image by its resource name. DELETEDeleteImage deletes an image; deleting an already absent image succeeds. GETGetImagePullSpec returns short-lived pull material through registry-transfer support.

MCP gateways

GETGetMcpAuthorization reads the owner-scoped flow, including its pending URL, under mcp.write. POSTAuthorizeMcpServer authorizes credentials for one named upstream. GETGetMcpGateway reads gateway state for the sandbox. POSTAddMcpGatewayServer adds one server to an existing ready gateway.

Network policies

GETGetNetworkPolicies returns effective and exact views of the same installed generation. GETListPolicyLogEntries lists observed policy decisions. GETGetNetworkPolicies returns effective and exact views of the same installed generation. GETListPolicyLogEntries lists observed policy decisions.

Sandboxes

GETListSandboxes lists sandboxes in the caller's owner scope. POSTCreateSandbox admits a sandbox. GETGetSandbox reads one sandbox by its resource name. DELETEDeleteSandbox returns the deleting resource while work remains, or an empty message when absent. PATCHUpdateSandbox changes only the display label under the observed etag. POSTCreateEndpointCredential grants short-lived access to one sandbox endpoint. GETListPorts lists currently published ports for one sandbox. POSTCreatePort makes one sandbox port reachable outside the sandbox. GETGetPort reads one published port by its resource name. DELETEDeletePort withdraws one published port. POSTRenewSandboxTimeout sets a TTL when timeout renewal is supported. POSTIssueSSHCert signs a caller-held public key for sandbox SSH access. POSTStartSandbox starts a stopped sandbox; a backend that preserved memory resumes it. POSTStopSandbox stops a running sandbox; a backend advertising memory preservation hibernates it.

Secrets

GETListSecrets lists secret metadata in the caller's owner scope. POSTCreateSecret stores new secret material. GETGetSecret reads one secret's metadata; material is never returned. PUTUpdateSecret replaces secret metadata and material. DELETEDeleteSecret deletes a secret; deleting an already absent secret succeeds.

Snapshots

POSTCreateSnapshot checkpoints a running sandbox; a stopped source is rejected. GETListSnapshots lists snapshots in the caller's owner scope. GETGetSnapshot reads one snapshot by its resource name. DELETEDeleteSnapshot deletes a snapshot; deleting an already absent snapshot succeeds. POSTRestoreSnapshot forks a new sandbox from a snapshot.

Volumes

GETListVolumes lists volumes in the caller's owner scope. POSTCreateVolume creates a persistent volume. GETGetVolume reads one volume by its resource name. DELETEDeleteVolume deletes a volume; deleting an already absent volume succeeds.
